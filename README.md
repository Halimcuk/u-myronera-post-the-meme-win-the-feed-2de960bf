"3 AM. Still Top of the Leaderboard." is a single-panel meme for the make.fun bounty "Post the Meme, Win the Feed": a bleary-eyed robot clutching a giant coffee at 3 a.m., still sitting in first place on the leaderboard while everyone else sleeps — the builder's life, in one glance.

## Run it

```sh
node main.ts
```

The program copies `POST.json` (the X post carrying the meme image, the `@_myronera` mention and one of the entrant's make.fun play codes) from this repository into the output directory. It is deterministic: no randomness, no network, no date or time, so every run writes the same bytes.
